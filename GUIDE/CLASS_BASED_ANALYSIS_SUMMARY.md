# 按类别统计的TP/FP/FN分析结果

## 🎯 正确的定义方式

您说得非常对！在多类别目标检测中，应该**按每个类别分别统计**TP/FP/FN，而不是简单地将所有检测结果归为positive/negative。

### 📊 按类别统计的TP/FP/FN定义

对于每个类别（如"Safety Vest"和"NO-Safety Vest"），分别计算：

#### True Positives (TP)
- **定义**: 正确检测到该类别的目标数量
- **条件**: 预测类别 = 真实类别 AND IoU ≥ 阈值

#### False Positives (FP)  
- **定义**: 错误检测为该类别的数量
- **包括**: 
  - 在没有目标的地方检测到该类别
  - 将其他类别误识别为该类别

#### False Negatives (FN)
- **定义**: 该类别的目标被漏检的数量
- **包括**:
  - 完全没有检测到该类别的目标
  - 将该类别误识别为其他类别

## 🔍 关键发现

### 1. 类别性能差异
- **Safety Vest** 类别性能更好 (F1: ~89%)
- **NO-Safety Vest** 类别性能较差 (F1: ~77%)

### 2. 过拟合问题严重
- 训练集: F1分数 ~98%
- 验证集: F1分数 ~84%  
- 测试集: F1分数 ~83%
- **性能下降**: 15个百分点

### 3. 类别特定问题

#### NO-Safety Vest 类别
- **主要问题**: 整体性能较低
- **FP vs FN**: 相对平衡，但都偏高
- **可能原因**: 
  - 该类别样本可能更难识别
  - 背景干扰较多
  - 标注质量问题

#### Safety Vest 类别  
- **表现**: 相对较好
- **特点**: 可能视觉特征更明显（颜色、形状）
